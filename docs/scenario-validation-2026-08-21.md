- 일정 기준: `TYPICAL`, 사용자가 입력한 검토기준일·공사기간과 카탈로그의 공식 처리기간만 반영

## 먼저 읽을 사항

아래 여섯 사례는 실제 사업장의 법률의견이 아니라, 현실적인 입력 조합으로 판정 엔진을 검증한 가상 사례다. 산업단지명, 고시번호, 사업부지는 실제 행정문서가 아니며, 계획승인 의제의 증거 게이트가 작동하는지 확인하기 위한 테스트 값이다. 따라서 `ACTIVE`는 “입력자가 모든 법정 사실을 확인했다고 진술한 경우 엔진이 예상 경로를 활성화했다”는 뜻이지, 시스템이 고시문 진위를 외부에서 검증했다는 뜻이 아니다.

화면 기준 집계는 다음과 같다.

- 적용: 검토 완료 포함규칙에 의해 `APPLIES`인 절차와, 상위 승인으로 의제되어 별도 수행하지 않는 절차를 합산했다.
- 확인 필요: `POSSIBLY_APPLIES`와 `NEEDS_MORE_INFO`를 합산했다.
- 비적용: `DOES_NOT_APPLY` 중 상위 절차에 의해 의제된 항목은 제외했다.
- 일정 하한: 미확인 기간을 0일로 두어 계산한 값이다. 총 소요기간으로 사용하면 안 된다.

## 1. 산단 내 반도체 공장 증설

### 입력 요약

- 충북 청주, 산업단지 입주계약 완료, 반도체 소자 제조, 기존 15,000㎡에서 총 20,000㎡로 증설
- 대기·폐수 배출시설, 유해화학물질, 위험물, 고압가스, 에너지사용계획 대상이라고 확인
- 반도체클러스터 신속처리: 신청자 지위, 지연 우려, 위원회 의결, 2026-08-15 장관 요청을 모두 확인했다고 입력
- 신속처리 요청목록: 대기배출시설·폐수배출시설
- 반도체클러스터 조성계획 승인·고시: 2026-08-20, 건축허가를 실제 의제항목이라고 입력

### 실제 판정과 순서

- 산업단지 입주계약은 `APPLIES`다.
- 공장설립·증설 승인은 입주계약 완료 경로에 의해 별도 수행하지 않고 의제된 것으로 표시됐다.
- 반도체 조성계획 승인 결과 절차는 `APPLIES`, 건축허가는 별도 수행하지 않는 계획승인 의제로 표시됐다.
- 신속처리 요청과 결과·기한 확인 절차는 모두 `APPLIES`다. 대기·폐수 인허가에는 신속처리 영향이 붙지만 면제되지는 않는다.
- 핵심 흐름은 `입주계약 → 장관 신속처리 요청 → 개별 대기·폐수 처리 및 결과·기한 확인`, 그리고 `조성계획 승인·의제 확인 → 착공신고 → 사용승인 → 산단 공장설립 완료신고`다. 개별 인허가와 결과 확인은 병행될 수 있어 단일 직렬 순서로 해석하면 안 된다.

### 기간·기관·남은 확인

- 총기간은 산정 불가, 확인된 하한은 1,259일이다.
- 기간 미확인: 자가용전기설비 사용전검사, 유해화학물질 취급시설 설치검사 및 정기·수시검사, 산업단지 입주계약, 배수설비 준공검사, 반도체 신속처리 요청·결과 확인, 반도체 조성계획 승인 결과 등 8개다.
- 핵심 기관 표기는 산업통상부, 입력한 산업단지 관리기관, 관할 환경부서 또는 위임기관, 관할 건축허가권자다. 실제 청주시·충북도 내 접수부서, 담당자, 위임기관은 미확인이다.
- 실제 법정 반도체클러스터 해당성, 사업시행자 지위, 장관 요청 공문 원본과 대상목록, 계획 승인·고시 원문, 관계기관 협의조건, 개별 처리계획 회신일·결과일·연장 여부를 추가 확인해야 한다.

## 2. 산단 내 이차전지 공장 신설

### 입력 요약

- 전북 군산, 산업단지 입주계약 진행 중, 30,000㎡ 이차전지 셀 공장 신설
- 소규모 환경영향평가, 환경오염시설 통합허가, 화학물질·위험물·고압가스·PSM 등 고위험 조건을 확인
- 국가첨단전략산업 신속처리: 법정 사업시행자 지위, 지연 우려, 위원회 의결, 2026-08-15 장관 요청을 확인했다고 입력
- 요청목록: 건축허가, 대기배출시설, 폐수배출시설

### 실제 판정과 순서

- 산업단지 입주계약, 전략산업 신속처리 요청, 결과·기한 확인이 `APPLIES`다.
- 공장설립승인은 산단 입주계약 경로 때문에 별도 절차에서 제외되지만, 입주계약이 완료된 상태가 아니므로 `isDeemed`는 붙지 않았다.
- 건축허가는 신속처리 영향이 붙은 확인필요 절차다. 환경오염시설 통합허가도 확인필요로 일정에 포함됐다.
- 대기·폐수 개별허가는 통합환경허가 경로의 제외규칙과 맞아 일정에서 제외되면서도 사용자가 입력한 신속처리 영향은 남는다. “신속처리 대상”과 “현재 실행할 개별 절차”가 같은 화면 상세에서 혼재할 수 있는 사례다.
- 핵심 흐름은 `장관 요청 → 처리계획·결과 추적`, `산단 입주계약 및 건축·통합환경허가 → 착공 → 사용승인 → 산단 완료신고`다.

### 기간·기관·남은 확인

- 총기간은 산정 불가, 확인된 하한은 1,259일이다.
- 기간 미확인 7개에는 신속처리 요청·결과 확인, 입주계약, 유해화학물질 검사, 전기 사용전검사, 배수설비 준공검사가 포함된다.
- 핵심 기관은 산업통상부와 개별 인허가 관계기관, 산업단지 관리기관, 기후에너지환경부장관, 관할 건축허가권자다. 실제 군산시·전북도 접수부서와 환경허가 담당기관은 미확인이다.
- 특화단지 지정과 사업시행자 지위, 실제 지연·현저한 지장 자료, 위원회 의결서, 장관 요청 공문, 통합환경허가 대상 업종·용량, 화학·PSM 세부 취급량을 확인해야 한다.
- 처리계획 15일, 결과 15일, 1회 연장, 조건부 60일 의제는 결과·연장 증거가 없어 일정 단축으로 반영되지 않았다.

## 3. 산단 내 바이오 공장 신설과 산업단지계획 통합승인

### 입력 요약

- 세종, 산업단지 입주계약 예정, 12,000㎡ 바이오의약품 공장 신설
- 산업단지계획의 법정서류 포함, 관계기관 협의, 2026-08-18 승인·고시 완료를 확인했다고 입력
- 의제항목: 공장설립승인, 건축허가, 개발행위허가

### 실제 판정과 순서

- 산업단지 입주계약과 산업단지계획 승인·의제 결과 확인이 `APPLIES`다.
- 선택한 공장설립승인·건축허가·개발행위허가 3개는 별도 수행하지 않는 의제로 정확히 표시됐다.
- 핵심 흐름은 `입주계약 및 산업단지계획 승인·의제 확인 → 착공신고 → 사용승인 → 산단 완료신고`다.
- 기존 산단에 단순 입주한다는 사실만으로 통합승인을 적용하지 않고, 계획승인 대상·서류·협의·승인고시 증거를 모두 입력한 경우에만 활성화됐다.

### 기간·기관·남은 확인

- 총기간은 산정 불가, 확인된 하한은 1,245일이다.
- 기간 미확인은 산업단지 입주계약, 산업단지계획 승인 결과, 전기 사용전검사, 배수설비 준공검사 4개다.
- 핵심 기관은 입력한 산업단지 관리기관, 산업단지 지정권자와 산업단지계획심의위원회, 개별 의제 인허가 관계기관이다. 구체적인 지정권자·위원회 사무국·접수부서는 미확인이다.
- 실제 사업시행자 자격, 계획 수립·변경 승인 대상성, 의제항목별 법정서류, 협의의견과 조건, 승인고시 원문을 대조해야 한다. 민간기업등의 6개월 기한은 접수일부터의 승인 여부 결정 상한이며 신청 준비기간이나 보완기간을 포함한 총기간이 아니다.

## 4. 개별입지 화학 공장과 지역특화발전특구계획

### 입력 요약

- 경북 포항 개별입지, 농지 30,000㎡ 화학제품 공장 신설
- 환경영향평가, 통합환경허가, 화학물질·위험물·고압가스·PSM, 재해·지하안전·국가유산 사전협의 조건을 확인
- 특구토지이용계획의 서류 포함, 관계기관 사전협의, 2026-08-19 승인·고시 완료를 확인했다고 입력
- 의제항목: 개발행위허가, 농지전용허가

### 실제 판정과 순서

- 특화특구계획 승인·의제 결과 확인은 `APPLIES`다.
- 개발행위허가와 농지전용허가는 계획승인 의제로 표시됐다.
- 공장설립승인, 통합환경허가, 건축허가, 사용승인, 개별입지 공장설립 완료신고는 확인필요 상태로 일정에 남았다.
- 핵심 흐름은 `공장설립·통합환경·건축 등 개별 검토 + 특구계획 승인·의제 확인 → 착공 → 사용승인 → 개별입지 완료신고`다. 환경·화학·안전 인허가는 지역특구계획을 입력했다는 이유만으로 자동 면제되지 않았다.

### 기간·기관·남은 확인

- 총기간은 산정 불가, 확인된 하한은 1,259일이다.
- 기간 미확인 6개는 개발행위 준공검사, 전기 사용전검사, 유해화학물질 설치·정기검사, 배수설비 준공검사, 특구계획 승인 결과다.
- 핵심 기관은 관할 시·군·구 공장·건축·개발행위 부서, 기후에너지환경부, 관할 환경청, 지방고용노동관서, 소방기관, 특구 담당 지방자치단체와 중소벤처기업부다. 정확한 권한분기와 접수기관은 미확인이다.
- 실제 지역특화발전특구 및 특구토지이용계획 포함 여부, 고시 원문, 농업진흥지역·전용면적, 화학물질 종류·수량, 배출량·시설용량, PSM 대상 공정, 환경평가 협의내용을 확인해야 한다.

## 5. AI 데이터센터 특별법 시행 전

### 입력 요약

- 검토기준일 2027-03-09, 강원 원주 개별입지, 40,000㎡ AI 데이터센터
- 특별법상 시설요건을 충족한다고 입력하고 일괄처리 완료, 계통영향평가 면제, 시설규모 산정, 산업단지 입지 특례를 선택
- 전력계통영향평가·에너지사용계획·교통·경관·건축위원회 대상이라고 개별 입력

### 실제 판정과 순서

- 선택한 네 특례는 모두 `FUTURE`다. 시행일 2027-03-10 전이므로 면제·의제·일괄처리 효과가 판정에 적용되지 않았다.
- 전력계통영향평가는 `APPLIES`로 남고, AI 일괄처리 신청·결과는 비적용이다.
- 공장설립승인·공장설립 완료신고·소규모 공장등록은 AI 데이터센터가 제조공장이 아니라는 업종 프로필 때문에 제외되며 특별법 시행 전 면제가 아니다.
- 핵심 흐름은 `개발행위·건축·전력계통영향평가 → 착공 → 사용승인`이다.

### 기간·기관·남은 확인

- 총기간은 산정 불가, 확인된 하한은 1,288일이다.
- 기간 미확인은 건축위원회, 개발행위 준공검사, 전기 사용전검사, 경관심의, 전력계통영향평가, 배수설비 준공검사 6개다.
- 핵심 기관은 관할 지자체 개발행위·건축 부서, 기후에너지환경부와 전력정책심의회, 소방기관이다. 구체적인 접수창구는 미확인이다.
- 특별법상 “완료”라는 입력값이 있어도 시행 전에는 효과가 새지 않는 날짜 게이트가 확인됐다.

## 6. AI 데이터센터 특별법 시행 후

### 입력 요약

- 검토기준일 2027-04-01, 그 밖의 사업조건은 시행 전 사례와 동일
- 특별법상 시설요건과 일괄처리 완료를 확인했다고 입력

### 실제 판정과 순서

- 일괄처리, 전력계통영향평가 면제, 시설규모 산정 특례, 산업단지 입지 특례가 모두 `ACTIVE`다.
- 전력계통영향평가는 별도 절차에서 제외됐다.
- 일괄처리 결과는 `APPLIES`, AI 데이터센터 입지·운영 신고는 일괄처리를 받은 상태에서만 의제됐다.
- 건축허가는 면제되지 않고 일괄처리 대상 및 시설규모 산정 특례가 표시된 확인필요 절차로 남는다.
- 공장설립 관련 절차는 업종 프로필로 제외되지만 `isDeemed`는 붙지 않았다.
- 핵심 흐름은 `개발행위·건축 등 일괄처리 대상 개별 검토 → 착공 → 사용승인 → 일괄처리 결과 확인`이다. 실제 관계기관 요청일과 처리결과일이 없어 150·90·40일 상한을 완료일로 자동 사용하지 않았다.

### 기간·기관·남은 확인

- 총기간은 산정 불가, 확인된 하한은 1,265일이다.
- 기간 미확인은 일괄처리 결과, 건축위원회, 개발행위 준공검사, 전기 사용전검사, 경관심의, 배수설비 준공검사 6개다.
- 핵심 기관은 과학기술정보통신부, 개별 인허가 관계기관, 관할 건축·개발행위 부서와 소방기관이다. 실제 관계기관 요청일, 거부 통지, 주민의견 청취, 연장 사유·기간은 미확인이다.
- 시행령상 AI 데이터센터 인정기준과 면제 전력용량이 아직 확정되지 않았으므로, 현재 입력의 시설요건 확인은 사용자 진술에 불과하다.

## 실제 기업이 “완벽히 파악”할 수 있는가

결론은 **아니다**. 현재 로드맵은 전국 공통 절차를 빠짐없이 떠올리고, 확인된 특례를 보수적으로 분기하며, 실행 전 질문 목록을 만드는 데는 유용하다. 그러나 여섯 사례 모두 총기간이 산정되지 않았고, 충분히 상세한 값을 입력해도 26~62개가 확인필요로 남았다. 실제 착수·예산·계약 의사결정을 이 결과만으로 확정하기에는 부족하다.

## 법적 안전장치 검증

- 산업단지·반도체·지역특구 계획은 서류 포함과 협의만으로 개별 인허가를 의제하지 않았다. 승인·고시 완료, 날짜, 고시문 근거, 법정 목록 안의 실제 의제항목이 있어야만 의제가 발생했다.
- URL/API로 계획 의제대상에 임의 ID만 주입해도 특별법 요약이 활성화되지 않도록 세 법률의 법정 목록으로 다시 제한했다.
- 산업단지 입주계약 예정·진행 상태는 공장설립승인 별도경로를 제외할 수 있지만, 계약 완료 증거 전에는 `isDeemed`를 표시하지 않는다.
- 여러 제외규칙이 동시에 맞더라도 실제 최종 제외규칙과 같은 의제근거를 가진 상위 절차가 확인된 경우에만 `isDeemed`가 붙는다.
- 국가첨단전략산업 신속처리는 2023-07-01, 반도체 특별법은 2026-08-11 이후의 장관 요청일만 허용한다.
- AI 데이터센터 특별법은 2027-03-10 전에는 면제·의제·일괄처리 효과를 적용하지 않는다.
- 신속처리 요청은 면제가 아니며, 결과·연장 증거가 없는 60일 조건을 자동 완료 또는 일정 단축으로 사용하지 않는다.
- 절차 표시 순서와 wave는 달력일·월 단위까지 포함한 모든 활성 선후행 간선을 사용하고, 업무일 CPM 산술만 업무일 간선으로 제한해 단위를 임의 변환하지 않는다. 실행계획에서는 검토 기준일에 시행 중인 권위 있는 `SEQUENCE` 인용이 연결된 선후행, 실무 권장 선행, 법정 분류·관계근거 보강 대상을 분리한다.

## 최종 판단

현재 제품은 “놓칠 수 있는 절차와 특별법 후보를 넓게 찾고, 확인된 증거가 없으면 면제·의제를 확정하지 않는 사전 진단·실행 체크리스트”로는 의미가 있다. 반면 “실제 지방투자기업이 필요한 인허가, 총기간, 정확한 관계부처와 접수처를 완벽히 파악하고 접수 이후를 관리하는 공식 실행 원장”에는 아직 못 미친다. 남은 우선순위는 공식 고시문 자동 검증, 신속처리 사건일자 모델, 관할기관 해소, 기간 근거 확충, 절차별 이행상태 관리 순이다.
