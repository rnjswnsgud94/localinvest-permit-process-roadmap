# 기업 인허가 실무자 관점 10개 시나리오 검증

- 검증일: 2026-08-23
- 대상 카탈로그: 145개 절차
- 재현 테스트: `tests/integration/investment-portfolio-regression.test.ts`
- 보고서 검증: 열 가지 입력 각각에 대해 실제 PDF를 메모리 렌더링하고 PDF 헤더, 페이지 구성, A3 가로 순서도 1장, 판정 집계, ELIS 링크 모델과 서버 식별자 비노출을 검사한다.
- 일정 원칙: 법정 상한, 단계별 기한, 신청인 준비기간, 보완 정지기간을 임의로 합산하지 않는다. 전체 구성요소가 확인되지 않으면 총 소요기간은 `null`로 유지한다.

## 결론

현재 출력은 필요한 절차 후보를 넓게 찾고 법적 근거가 확인되지 않은 면제·의제를 막는 사전진단 도구로는 유효하다. 실무자가 이 결과만으로 접수부터 가동까지 관리하려면 먼저 `확정·잠정 판정 분리`, `절차별 이행 원장`, `임계값 판정 계산기`, `관할기관 해소`, `사건일 기반 법정시계`, `고시 원문 검증`이 필요하다.
